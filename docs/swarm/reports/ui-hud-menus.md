# ui-hud-menus report

## What I built
- `game/assets/ui/theme.tres` (generated by `scripts/ui/build_theme.gd` from `UITheme.build()`): dark translucent panels, cheese-yellow accent, SystemFont (Inter / Noto Sans / DejaVu fallbacks).
- `scripts/ui/`: `ui_root.gd` (UIRoot, routes Game.state -> screen, mouse mode, applies saved bindings/display), `hud.gd` (health, lives pips, ammo/reserve, weapon icon, score, keys, toasts, level card, damage/low-health vignette shader), `crosshair.gd` (spread, bloom kick, hit/kill/headshot markers), `hud_icons.gd` (vector weapon/key/life icons), `menu_screen.gd` base, `title_menu.gd` (cheese emblem, New Game + skill, Settings, Quit), `pause_menu.gd`, `intermission.gd` (count-up tally, par, bonus), `end_screen.gd` (game over + victory), `settings_menu.gd` (quality, resolution, fullscreen, vsync, FOV, sensitivity, invert Y, 3 volumes, key rebinding with reset), `ui_prefs.gd`, `cheese_emblem.gd`, `ui_theme.gd`.
- `scenes/ui/ui_root.tscn`, `scenes/ui/ui_preview.tscn/.gd` (fake-Events screenshot harness, `--screen=title|hud|pause|settings|keys|intermission|gameover|victory`).
- `tests/test_ui.gd` (8 tests).

## Verification evidence

- Parse check clean (no warnings from my files).
- Looked at GPU screenshots in `out/ui-shots/` (title, hud, pause, settings, keys, intermission): layout and look correct; fixed toast/health-panel overlap and invisible checkboxes after viewing. Game over / victory shots rendered without error but not viewed.

## Deviations from the contract
- Resolution and key bindings are stored in `user://ui_prefs.cfg` (UIPrefs), not `Settings`, because `Settings.get_value` logs errors for keys missing from DEFAULTS.
- Fullscreen/resolution are applied by `SettingsMenu.apply_display()`; `Settings.apply()` ignores the `fullscreen` key.
- Crosshair spread and hit markers use optional Events signals (below); fallbacks: ammo drop kicks the bloom, `enemy_killed` shows a kill marker.

## Mistakes I made and how I fixed them
- Used `UITheme` in a `--script` before the class cache existed: use `preload`, and run `--import` after adding class_names.
- Called `Settings.get_value` for unknown sections (error spam): moved to UIPrefs.
- Checkbox icons invisible on dark theme: generated custom icons.

## Learnings for a future agent
- After adding `class_name` files run `tools/godot.sh --headless --path game --import` before tests/shots.
- Regenerate the theme after editing `ui_theme.gd`: `tools/godot.sh --headless --path game --script res://scripts/ui/build_theme.gd`.
